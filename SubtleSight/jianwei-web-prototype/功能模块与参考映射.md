# 见微 Web 功能模块与界面参考

## 功能块

| 功能区 | 用户任务 | 主要界面 |
|---|---|---|
| 发现 | 从全网候选中发现相关、正在发生、重要和最新的信号 | 多视角信息流、筛选器、信号预览 |
| 事件脉络 | 将同一事件的多来源报道、变化、Claim 和证据放在一起判断 | 事件摘要、时间线、证据轨、来源列表 |
| 深度研究 | 对问题进行计划、搜索、阅读、证据抽取、补缺和报告 | 研究计划、实时步骤、证据矩阵、报告编辑区 |
| Watchlist | 持续跟踪公司、产品、Repo、论文、政策和假设 | 跟踪表、变化幅度、基线、提醒 |
| 知识库 | 检索已保存资料、Claim、实体关系和历史研究 | 混合搜索、类型筛选、知识详情 |
| 报告 | 生成日报、周报、专题、变化报告并导出或发布 | 报告列表、编辑预览、版本和发布状态 |
| 信源 | 管理 RSS、网站、GitHub、论文、新闻、社区和搜索 Provider | 健康表、连接器、抓取计划、错误详情 |
| 自定义视图 | 用实体、主题、来源、关键词和排除规则组合专属发现流 | 规则构建器、实时结果预览、通知设置 |
| 任务中心 | 查看采集、索引、研究和发布的后台状态 | 队列表、进度、重试、暂停、错误 |
| 设置 | 配置模型、搜索 Provider、预算、安全、存储和备份 | 分组表单、凭据状态、配额、诊断 |
| 全局 Agent | 用自然语言跨功能区查询、创建和触发任务 | 右侧抽屉、工具步骤、确认门禁 |

## 参考映射

| 参考产品 | 借鉴范围 | 在见微中的改造 |
|---|---|---|
| Feedly / Inoreader | 订阅源、信息流视图、稍后读、Source Health | 从文章流升级为 Story/Signal 流，并加入主动 Web Discovery |
| Reddit | Home、Rising、Latest、Custom Feed、Thread | 不采用社区边界；改造成 For You、Emerging、Saved View 和事件脉络 |
| Perplexity Deep Research | 研究进度、来源和最终回答 | 增加结构化计划、Claim/Evidence、预算和可恢复状态 |
| NotebookLM | Sources、Chat、Studio 三栏关系 | 改造成研究计划、报告正文和编号证据轨 |
| GitHub Notifications | 高密度收件箱、过滤、Done/Save | 用于信号流的批量筛选、状态和快捷动作 |
| GitHub Issues / PR | 事件时间线、引用、状态变化和讨论 | 用于 Story Timeline 与研究版本历史 |
| GitHub Trending | 时间窗口、语言/类型筛选、排名 | 用于 Emerging 和 Important 的筛选结构，不复制 Stars 排名 |
| Linear | 侧栏、Saved View、紧凑表格、命令式操作 | 用于整体导航密度、自定义视图和任务中心 |
| Semi Design | 表格、筛选、Drawer、Tabs、Tag、表单状态 | 作为组件和交互语言，不混用 Ant Design |

## 视觉锁定

- 主方向：Swiss 高密度信息工作台。
- 保留：白色画布、单一无衬线、1px 网格线、左对齐、紧凑行高、数字化证据轨。
- 主色：International Orange `#FF4F00`，只用于主操作、当前焦点和关键进行中状态。
- 次级语义：蓝色信息、绿色成功、琥珀警告、红色危险。
- 圆角：2-6px；无装饰阴影；主要通过边框和分栏建立层次。
- 记忆点：Story 与 Research 中贯穿页面的编号证据轨。
- 拒绝：紫色渐变、深色默认、卡片墙、装饰性大标题、社区化帖子流、假数据仪表盘。
